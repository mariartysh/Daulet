# 🎾 Court Hunter — Daulet Tennis Academy

Бот-охотник: сам следит за расписанием на tennisdaulet.altegio.me, бронирует корты по вашему фильтру, шлёт уведомления в Telegram и выключается, когда цель достигнута.

**Состав:**
- `public/index.html` — веб-панель (адаптивная, тёмная)
- `api/tick.js` — охота (дергается внешним пингером)
- `api/telegram.js` — Telegram-бот (webhook)
- `api/app.js` — API панели
- `lib/` — логика: Altegio API, матчинг фильтра, дедлайны отмены

**Правила, зашитые в бота:**
- Крытых кортов 8 (№1–8), уличных 5 (№1–5), нумерация раздельная; фильтр «любой корт» / конкретные номера в рамках типа.
- Бронь возможна только на сегодня/завтра/послезавтра — так работает сайт.
- Длительность: 1 / 2 / 3 часа.
- Онлайн-отмена — не позднее чем за **5 часов** до начала; через ресепшн (звонком) — за **3 часа**. Бот показывает оба дедлайна и напоминает за час до закрытия онлайн-отмены.
- Слот «**завтра 00:00**» — это **сегодня в полночь**: учитывается в фильтре («вечер до 24:00») и в расчёте дедлайнов.
- Анти-дубль: один слот не бронируется и не предлагается дважды.
- Автостоп: набрали цель (например, 3 брони) — задание выключается, приходит итоговое сообщение.

> 💡 Вся эта инструкция в удобном виде есть и внутри панели — вкладка **«Запуск в бой»**.

## Деплой (≈10 минут)

### Шаг 1. Telegram-бот
1. В Telegram откройте **@BotFather** → `/newbot` → имя и username.
2. Скопируйте **токен** (вида `123456789:AA...`) → это `TELEGRAM_TOKEN`.

### Шаг 2. База (бесплатно)
1. Зарегистрируйтесь на **upstash.com** → Create Database (Redis, любой регион).
2. На странице базы во вкладке **REST API** скопируйте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

### Шаг 3. Токен Altegio (2 минуты)
API сайта требует заголовок авторизации — его использует сам виджет бронирования, снимаем оттуда:
1. Откройте https://tennisdaulet.altegio.me/company/521176/personal/menu в Chrome.
2. `F12` → вкладка **Network** → в фильтре введите `api`.
3. Пощёлкайте по виджету (выберите услугу/дату), появятся запросы вида `book_services`, `book_times`.
4. Кликните любой → **Headers → Request Headers → Authorization** → скопируйте **всё значение целиком** (например `Bearer abc123...`).
5. Это `ALTEGIO_AUTH`. Токен виджета обычно долгоживущий; если бот начнёт получать 401 — снимите заново.

### Шаг 4. Vercel
1. Залейте папку в GitHub-репозиторий (или используйте `vercel` CLI: `npx vercel deploy` из этой папки).
2. На vercel.com → **Add New Project** → импортируйте репозиторий. Настроек сборки не нужно (статический `public/` + функции `api/`).
3. **Settings → Environment Variables** — добавьте всё из `.env.example` (свои значения!). Случайные строки для `TG_SECRET`, `TICK_KEY`, `CRON_SECRET` можно взять из генератора паролей.
4. Deploy. Запомните адрес, например `https://court-bot.vercel.app`.

### Шаг 5. Подключить Telegram-webhook
Откройте в браузере (подставьте своё):

```
https://api.telegram.org/bot<TELEGRAM_TOKEN>/setWebhook?url=https://<ваш-домен>.vercel.app/api/telegram&secret_token=<TG_SECRET>
```

Должно ответить `{"ok":true,...}`. Затем напишите боту свой пароль одним сообщением — чат подключится, придёт меню с кнопками.

### Шаг 6. Пингер (охота каждые ~15–30 сек)
На бесплатном Vercel встроенный cron работает лишь раз в день (он оставлен под ежедневную сводку). Частый опрос делает внешний бесплатный пингер:
1. Зарегистрируйтесь на **cron-job.org** → Create cronjob.
2. URL: `https://<ваш-домен>.vercel.app/api/tick?key=<TICK_KEY>`
3. Расписание: **каждую минуту**. Таймаут: 30 сек.
4. Каждый вызов бот делает 2 прохода с паузой 15 сек (`SWEEPS_PER_CALL`, `POLL_INTERVAL_SEC`) — фактическая частота проверки ~15–45 сек. Нужно ровно каждые 15 сек — возьмите Vercel Pro (cron `* * * * *`) и поставьте `SWEEPS_PER_CALL=3`.

### Шаг 7. Проверка
1. Откройте `https://<ваш-домен>.vercel.app` → пароль → панель.
2. Нажмите **«Тест подключения»** — должно показать `Altegio: ✅` со списком кортов, `TG: ✅`, `База: ✅`.
3. Заполните имя/телефон, настройте фильтр, **«Запустить охоту»**. Дальше всё само.

## Управление из Telegram
Всё на кнопках, команды видны в синей кнопке «☰» рядом с полем ввода:
- `/menu` — главное меню (запуск/стоп, Когда, Фильтр, Кто играет, Брони, Статус, панель)
- `/status` · `/bookings` · `/stop` · `/help`
- Без пароля бот не пускает никуда: любое сообщение или кнопка от незнакомца — просьба прислать пароль
- Друг подключается так же: присылает пароль одним сообщением

### Админ-панель (только владелец)
В главном меню появляется кнопка «👑 Админ-панель» у аккаунта из `ADMIN_USERNAME`: список подключённых чатов (имя, @username, id), кнопка «🚫 Отключить» для каждого, текущий пароль и смена пароля командой `/key НовыйПароль`. У остальных команда не существует и нигде не упоминается.

## Telegram мини-апп (панель прямо в Telegram)
В @BotFather: `/mybots` → ваш бот → **Bot Settings → Menu Button → Edit menu button URL** → вставьте адрес панели (`https://<ваш-домен>.vercel.app`). Теперь панель открывается кнопкой слева от поля ввода — с темой Telegram и запоминанием входа.

## Если бот «ничего не находит» — диагностика в один клик
Откройте в браузере: `https://<ваш-домен>.vercel.app/api/diag?key=<TICK_KEY>`
Покажет: какая база API ответила, список кортов с сайта (и как бот их распознал), список услуг с ценами и длительностями, живое расписание по первым трём кортам и сколько кортов подходит под ваш фильтр.

Частые причины пустого поиска:
1. **Устарел ключ** — в диагностике статус 401/403. Снимите `ALTEGIO_AUTH` заново (шаг 3).
2. **Длительность не влезает в окно** — 3 часа в окно 20:00–22:00 = ноль вариантов. Теперь окно расширяется автоматически, но проверьте подпись «старты с … до …».
3. **Слишком узкий фильтр** — конкретный номер + один день + час пик. Смотрите «подходит_под_фильтр» в диагностике.
4. **Ночные слоты** — играть можно до 01:00, но на сайте это «завтра 00:00/01:00». Поставьте конец окна «00:00 · полночь» или «01:00 · ночью» — бот сам заглянет в следующую дату.
5. **Корты заданы услугами, а не «сотрудниками»** — бот понимает оба варианта (раньше только первый).

## Как это устроено
Каждый тик: `book_staff` (список кортов, кэш 6ч) → `book_times` по комбинациям день×корт (не более `COMBO_CAP=8` запросов за проход, с ротацией; дни — сегодня/завтра/послезавтра) → новые слоты сверяются с фильтром (тип, номер, время, длительность 1/2/3 ч) → автобронь `book_record` или уведомление с кнопкой. Ответ `book_record` даёт `id+hash` — по ним работает отмена из бота (`DELETE user/records/{id}/{hash}`).

## Важно
- Инструмент для **личного** пользования: интервалы щадящие, не ставьте `POLL_INTERVAL_SEC` ниже 10 и `COMBO_CAP` выше 10.
- Данные (имя/телефон/почта) хранятся только в вашей базе Upstash.
- Если клуб сменит правила отмены — поправьте константы `5 * 3600e3` и `3 * 3600e3` в `lib/logic.js`.
